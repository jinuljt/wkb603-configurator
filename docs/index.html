WKB603 Configurator

点击键帽，选择新用途，检查完整方案，再保存到键盘。

第一版范围

macOS 13+ 原生应用，支持 Apple Silicon 与 Intel 通用二进制，MIT 开源。使用 SwiftUI、Foundation、CryptoKit 与 IOKit，无第三方运行时依赖。没有网络请求、云服务、统计、按键监听或固件刷写。

界面显示本地方案，不能读取键盘中已保存的完整键位表。写入会替换整张普通层改键表，未列出的按键恢复默认。请先把需要保留的所有改键加入方案。Fn 层与灯效配置不发送。

旋钮与按键

v0.1.2 已完成实际界面检查：圆形旋钮和刻度正常显示，按压、逆时针、顺时针入口分别进入静音、音量减、音量加编辑状态。该检查只选择本地编辑目标，没有修改方案或写入设备。

右上角按实际外形显示为一个圆形旋钮。点击旋钮，在弹出面板选择按压、逆时针或顺时针操作，再在右侧编辑其功能。默认分别为静音、音量减和音量加；旋转操作的自定义改键尚未实机验证。

使用步骤

  1. 用 USB 数据线连接键盘，关闭无线开关。
  2. 点击键帽，在右侧选普通键、组合键或媒体功能，再点“添加到方案”。蓝色键帽表示本地已修改。
  3. 可导入 JSON 方案、导出备份，或载入三键示例。编辑与载入都不会自动写入键盘。
  4. 点击“检查并写入键盘”预览整份清单；未连接或未授权时仍可预览，但不能写入。
  5. 系统需要时，在“隐私与安全性 → 输入监控”允许 WKB603 Configurator，按系统提示重新打开应用。此系统权限范围较广，应用不订阅输入事件。
  6. 核对清单和覆盖范围，点击写入。完成后测试按键，保持无线 OFF 拔线约 10 秒后重插复测。使用结束可关闭权限并退出应用。

只做临时代码签名，没有 Apple Developer ID 签名或公证。下载版可能被系统阻止；参考 Apple 打开应用的官方说明，也可以从源码构建。

实机证据和限制

项目结果
已验证设备一把白光 WKB603 / JZ990，USB 产品名 WKB603，厂家 hfd.cn，VID 05ac / PID 024f。
已验证配置Insert → Command+Shift+2；Cal → Command+Space；Pause → 播放／暂停。独立原生写入工具的结果由用户确认：三键拔线重插后正常，原按键扩散灯效正常。
GUI 复用GUI 方案构造器生成的三键报告摘要与实机版本逐字节一致。GUI 通用包编译和离线检查通过。GUI 实机写入尚未单独复测；Intel 仅交叉编译，未在 Intel 硬件执行。
不保证其他批次、RGB 版、RS2、其他型号，蓝牙、2.4 GHz 和跨电脑行为，以及尚未测试的其他键位和组合。
固件不包含、不调用任何固件更新路径。USB bcdDevice 字段不能直接作为固件版本判断依据。

失败处理

每个控制命令检查返回命令和成功状态；任何发送、读取或确认失败立即停止后续命令。失败前可能已有部分命令发出，请拔线重插后再操作。应用没有设备配置备份功能，导出的文件是本地方案备份。

报告 ID 为 0。Windows 的 65 字节缓冲区包含额外报告 ID 字节，macOS 的 IOHIDDeviceSetReport 负载不包含它。确认响应要求负载前两字节与请求一致，第 4 字节为 01。

默认槽为 00 00 00 00；普通键／组合键为 02 modifier usage 00，modifier 采用标准 USB HID 修饰键位掩码；已验证的媒体播放／暂停为 03 cd 00 00。界面只提供明确编码的目标列表，Fn 不可编辑。
